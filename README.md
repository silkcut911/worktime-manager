# 출퇴근 시간관리

[워크타임 매니저 열기](https://silkcut911.github.io/worktime-manager/)

스마트폰에서 출퇴근 시간과 계획을 입력하고 근무시간을 확인하는 앱입니다. 데이터는 사용 중인 기기의 브라우저에 저장됩니다. 개발·계산 규칙은 [AGENTS.md](AGENTS.md)에 정리되어 있습니다.

## 시간 선택 휠 사용법

2026-11-16 스마트폰에서 확인한 최종 동작입니다. 시간 칸을 누르면 시·분 선택 휠이 열립니다.

| 조작 | 동작 |
|---|---|
| 손가락을 대고 끌기 | 끈 거리만큼 여러 칸 움직입니다. 한 칸으로 제한하지 않습니다. 네 칸 길이를 끌면 네 칸 이동합니다. |
| 끌다가 멈추고 놓기 | 손가락을 멈추면 휠도 멈춥니다. 놓으면 관성 없이 가까운 숫자에 맞춥니다. |
| 살짝 튕기기 | 천천히 관성으로 회전합니다. |
| 빠르게 튕기기 | 빠르게 관성으로 회전합니다. |
| 돌아가는 휠 누르기 | 가까운 숫자에서 멈춥니다. |
| 멈춰 있는 휠의 숫자 누르기 | 누른 숫자를 선택합니다. |

가운데 크고 진한 숫자가 선택값이며, 위아래 숫자는 흐리게 표시됩니다. 휠에는 다섯 줄이 보이고 분은 1분 단위입니다. 분이 59에서 00으로 넘어가면 시가 1 증가하고, 00에서 59로 넘어가면 시가 1 감소합니다. 출근·퇴근의 시는 0~23, 제외·추가제외의 시는 0~9에서 순환합니다.

휠 아래 `− / +` 버튼은 없습니다. **확인**을 누르면 선택한 시간이 입력됩니다. **취소**하거나 창 바깥을 누르면 기존 값을 유지하고, **지우기**를 누르면 해당 시간 칸을 비웁니다. 날짜 카드의 **저장** 버튼으로 기록을 저장합니다.

설정 → **시간 입력 방식**에서 **숫자 입력**으로 바꿀 수도 있습니다. 예를 들어 `950`은 `9:50`으로 입력됩니다. 숫자 입력 모드에서 제외·추가제외의 한두 자리 숫자는 분으로 처리합니다(`30` → `0:30`).
